# Vulners API SDK skill

This directory contains a repository-scoped skill for working on the Vulners Python API SDK.
The source-of-truth location in this repository is:

```text
.agents/skills/vulners-api/
```

Main entry point:

```text
SKILL.md
```

Supporting files:

```text
references/repo-layout.md
references/api-overview.md
references/tool-selection.md
scripts/smoke_vulners_api.py
```

The skill is designed for Codex-compatible agent harnesses that read repository skills from
`.agents/skills/`. If copied to another checkout of the Vulners SDK, the final path should be:

```text
.agents/skills/vulners-api/SKILL.md
```
