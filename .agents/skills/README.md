# Agent skills

This directory contains repository-scoped agent skills.

## Included skill

- `vulners-api/`: guidance for maintaining the Vulners Python API SDK safely, including security rules, testing expectations, and defensive example patterns.

## Installation

This repository already has the skill in its active location. For another checkout of the Vulners
SDK, copy this repository's `.agents/` directory to the root of that target checkout:

```bash
cp -R /path/to/source/vulners-sdk/.agents /path/to/target/vulners-sdk/
```

Expected final location:

```text
.agents/skills/vulners-api/SKILL.md
```
